.Font Outlines

[[req-font-outlines-outline]]
===== Font `outline` property

[requirement]
====
[%metadata]
identifier:: /req/font-outlines/outline
part:: An Encoding SHALL support defining an `outline` Font property as a FontOutline object including a `size`, an `opacity` and a `color`.
part:: A Renderer SHALL support drawing an outline around the glyphs of text drawn with a Font specifying an `outline`, beneath the glyphs themselves.
====

[[req-font-outlines-size]]
===== FontOutline `size` property

[requirement]
====
[%metadata]
identifier:: /req/font-outlines/size
part:: An Encoding SHALL support defining a `size` FontOutline property as a float.
part:: A Renderer SHALL support drawing the outline extending outward from the glyph contours by the thickness specified by the `size` property.
====

[[req-font-outlines-opacity]]
===== FontOutline `opacity` property

[requirement]
====
[%metadata]
identifier:: /req/font-outlines/opacity
part:: An Encoding SHALL support defining an `opacity` FontOutline property as a float between 0 (fully transparent) and 1 (fully opaque).
part:: A Renderer SHALL support drawing the outline with the opacity specified by the `opacity` property.
====

[[req-font-outlines-color]]
===== FontOutline `color` property

[requirement]
====
[%metadata]
identifier:: /req/font-outlines/color
part:: An Encoding SHALL support defining a `color` FontOutline property as a Color.
part:: A Renderer SHALL support drawing the outline in the color specified by the `color` property.
====

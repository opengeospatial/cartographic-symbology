[[req-math-abs]]
===== Math `abs` function

[requirement]
====
[%metadata]
identifier:: /req/math/abs
part:: An Encoding SHALL support defining a call to the `abs` standard function taking one numeric argument.
part:: A Renderer SHALL support evaluating `abs(x)` as the absolute value of `x`.
====

[[req-math-acos]]
===== Math `acos` function

[requirement]
====
[%metadata]
identifier:: /req/math/acos
part:: An Encoding SHALL support defining a call to the `acos` standard function taking one numeric argument.
part:: A Renderer SHALL support evaluating `acos(x)` as the arc cosine of `x`, in radians, in the range [0, π].
====

[requirement]
====
[%metadata]
identifier:: /req/math/atan2

part:: A Renderer SHALL support evaluating `atan2(y, x)` as the angle, in radians in the range [-π, π], between the positive x axis and the point (`x`, `y`).

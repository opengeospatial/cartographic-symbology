[[req-coverage-color-channels]]
===== Symbolizer `colorChannels` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/color-channels
part:: An Encoding SHALL support defining a `colorChannels` Symbolizer property as a Color object.
part:: A Renderer SHALL support portraying each coverage cell with the red, green and blue components resolved from the `colorChannels` property for that cell.
====

[[req-coverage-alpha-channel]]
===== Symbolizer `alphaChannel` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/alpha-channel
part:: An Encoding SHALL support defining a `alphaChannel` Symbolizer property as a float.
part:: A Renderer SHALL support portraying each coverage cell with the opacity resolved from the `alphaChannel` property for that cell, where 0 is fully transparent and 1 is fully opaque.
====

[[req-coverage-single-channel]]
===== Symbolizer `singleChannel` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/single-channel
part:: An Encoding SHALL support defining a `singleChannel` Symbolizer property as a float.
part:: A Renderer SHALL support using the value resolved from the `singleChannel` property for each coverage cell as the input value to the `colorMap` and `opacityMap` properties.
====

[[req-coverage-color-map]]
===== Symbolizer `colorMap` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/color-map
part:: An Encoding SHALL support defining a `colorMap` Symbolizer property as an array of `value` (float) and `color` (Color) pairs which can be tagged with a `name`.
part:: A Renderer SHALL support portraying each coverage cell with the color mapped from its `singleChannel` value by the `colorMap`, interpolating linearly between the colors of the two closest entries and using the color of the first or last entry for values outside the range of the map.
====

[[req-coverage-opacity-map]]
===== Symbolizer `opacityMap` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/opacity-map
part:: An Encoding SHALL support defining a `opacityMap` Symbolizer property as an array of `value` (float) and `opacity` (float) pairs which can be tagged with a `name`.
part:: A Renderer SHALL support portraying each coverage cell with the opacity mapped from its `singleChannel` value by the `opacityMap`, interpolating linearly between the opacities of the two closest entries and using the opacity of the first or last entry for values outside the range of the map.
====

[[req-coverage-gamma]]
===== Symbolizer `gamma` property

[requirement]
====
[%metadata]
identifier:: /req/coverage/gamma
part:: An Encoding SHOULD support defining a `gamma` Symbolizer property as a float.
part:: A Renderer SHOULD support applying a gamma correction to the portrayed color values, using the value of the `gamma` property as the exponent applied to normalized (0 to 1) color components.
====

[[req-labels-label]]
===== Symbolizer `label` property

[requirement]
====
[%metadata]
identifier:: /req/labels/label
part:: An Encoding SHALL support defining a `label` Symbolizer property as a Label, which is a MultiGraphic that can contain multiple graphical elements.
part:: A Renderer SHALL support drawing the graphical elements of the labels as a separate pass on top of all styled vector features and coverages.
part:: A Renderer SHALL support omitting labels which cannot be placed without overlapping other labels.
====

[[req-labels-placement]]
===== Label `placement` property

[requirement]
====
[%metadata]
identifier:: /req/labels/placement
part:: An Encoding SHALL support defining a `placement` Label property as a LabelPlacement object including a `priority`, a `minSpacing` and a `maxSpacing`.
part:: A Renderer SHALL support placing labels so that a label with a higher `priority` is placed in preference to a conflicting label with a lower `priority`.
part:: A Renderer SHALL support repeating a label so that the distance between repetitions of that label is at least `minSpacing` and, where space allows, at most `maxSpacing`.
====

[[req-casing-casing]]
===== Stroke `casing` property

[requirement]
====
[%metadata]
identifier:: /req/casing/casing
part:: An Encoding SHALL support defining a `casing` Stroke property as a StrokeStyling object.
part:: A Renderer SHALL support drawing the casing of a stroke along the same geometry as the stroke, using the StrokeStyling specified by the `casing` property, beneath the main stroke.
part:: A Renderer SHALL support drawing the casing so that it extends the `width` of the casing beyond each side of the main stroke, for a total width of the main stroke's `width` plus twice the casing's `width`.
part:: A Renderer SHALL support drawing, within a single visualization pass, the casings of all features with the same `zOrder` beneath the main strokes of all those features, so that the casings of crossing and joining lines merge.
====

NOTE: A Renderer can also draw the casings and main strokes together, e.g. in a single rendering pass using signed distance fields, as long as the result is the same. A style that needs the casing and main stroke of each feature drawn in turn can use visualization passes or feature passes instead.

[[req-casing-center]]
===== Stroke `center` property

[requirement]
====
[%metadata]
identifier:: /req/casing/center
part:: An Encoding SHALL support defining a `center` Stroke property as a StrokeStyling object.
part:: A Renderer SHALL support drawing the center line of a stroke along the same geometry as the stroke, using the StrokeStyling specified by the `center` property, on top of the main stroke.
====

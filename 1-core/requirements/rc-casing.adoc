[[req-casing-casing]]
===== Stroke `casing` property

[requirement]
====
[%metadata]
identifier:: /req/casing/casing
part:: An Encoding SHALL support defining a `casing` Stroke property as a StrokeStyling object.
part:: A Renderer SHALL support drawing the casing of a stroke along the same geometry as the stroke, using the StrokeStyling specified by the `casing` property, beneath the main stroke.
====

[[req-casing-center]]
===== Stroke `center` property

[requirement]
====
[%metadata]
identifier:: /req/casing/center
part:: An Encoding SHALL support defining a `center` Stroke property as a StrokeStyling object.
part:: A Renderer SHALL support drawing the center line of a stroke along the same geometry as the stroke, using the StrokeStyling specified by the `center` property, on top of the main stroke.
====

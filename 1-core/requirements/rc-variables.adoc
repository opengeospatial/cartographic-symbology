[[req-variables-definition]]
===== Variable definitions

[requirement]
====
[%metadata]
identifier:: /req/variables/definition
part:: An Encoding SHALL support defining named variables, each associated with an Expression providing its value.
part:: A Renderer SHALL support allowing an application to override the value of a defined variable at run time (e.g., from a slider or drop-down control).
====

[[req-variables-expression]]
===== Variable expressions

[requirement]
====
[%metadata]
identifier:: /req/variables/expression
part:: An Encoding SHALL support defining a VariableExpression referencing a variable by its `name` anywhere an Expression is allowed.
part:: A Renderer SHALL support resolving a VariableExpression to the current value of the referenced variable.
====

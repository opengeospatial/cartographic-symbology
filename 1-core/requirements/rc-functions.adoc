[[req-functions-call-expressions]]
===== Function call expressions

[requirement]
====
[%metadata]
identifier:: /req/functions/call-expressions
part:: An Encoding SHALL support defining a FunctionCallExpression identifying the Function to call and an ordered list of zero or more argument Expressions.
part:: A Renderer SHALL support evaluating a FunctionCallExpression by evaluating its arguments and resolving the expression to the value returned by the Function, of the Function's return type.
part:: A Renderer SHALL support an `integer` argument where the parameter of the Function is a `number`.
part:: A Renderer SHALL support converting a `string` argument to the enumeration value of that name, where the parameter of the Function is of an enumeration type.
part:: A Renderer SHALL evaluate a FunctionCallExpression whose arguments do not match the parameters of the Function, in number or type, after these conversions, to NULL.
====

NOTE: A Function can define itself which arguments match its parameters. The arguments of `format` match when they match the conversion specifiers of its format string.

[[per-functions-type-casts]]
[permission]
====
[%metadata]
identifier:: /per/functions/type-casts
part:: A Renderer MAY convert arguments of other types to the type of the parameter, as CQL2 Permission 2 (`/per/basic-cql2/type-casts`) allows. How such arguments are converted is not specified.
====

[[req-functions-standard-functions]]
===== Standard functions

[requirement]
====
[%metadata]
identifier:: /req/functions/standard-functions
part:: An Encoding SHALL support identifying standard functions by their name, with the name mapping to the URI of the standard function.
part:: A Renderer SHALL support standard functions as specified by the requirements class defining them, with the parameters, return type and behavior defined there.
====

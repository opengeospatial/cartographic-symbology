[[req-text-manipulation-case-insensitize]]
===== Text `caseInsensitize` function

[requirement]
====
[%metadata]
identifier:: /req/text-manipulation/case-insensitize
part:: An Encoding SHALL support defining a `caseInsensitize` function that makes a string suitable for case-insensitive comparison.
part:: A Renderer SHALL support evaluating the `caseInsensitize` function such that two strings differing only in letter case compare as equal once both are case-insensitized (equivalent to the CQL2 `CASEI` function).
====

[[req-text-manipulation-accent-insensitize]]
===== Text `accentInsensitize` function

[requirement]
====
[%metadata]
identifier:: /req/text-manipulation/accent-insensitize
part:: An Encoding SHALL support defining an `accentInsensitize` function that removes accents from a string.
part:: A Renderer SHALL support removing accents from a string using the `accentInsensitize` function (equivalent to the CQL2 `ACCENTI` function).
====

==== Basic Vector Features Styling

[[rc-table-vector]]

[requirements_class]
.Basic Vector Features Styling
====
[%metadata]
identifier:: http://www.opengis.net/spec/cartosym-1/2.0/req/vector

[[req-vector-fill]]
===== Symbolizer `fill` property

[requirement]
====
[%metadata]
identifier:: /req/vector/fill
part:: An Encoding SHALL support defining a `fill` Symbolizer property as an object including a `color` and an `opacity`.
part:: A Renderer SHALL support filling vector geometry based on a `fill` property specifying a `color` and an `opacity`.
====

[[req-vector-stroke]]
===== Symbolizer `stroke` property

[requirement]
====
[%metadata]
identifier:: /req/vector/stroke
part:: An Encoding SHALL support defining a `stroke` Symbolizer property as an object including a `color` and a units of measure-qualified ("uom-qualified") `width`.
part:: A Renderer SHALL support drawing the stroke of vector geometry based on a `stroke` property specifying a `color` and a uom-qualified `width`.
====

[[req-vector-units]]
===== Graphical Units of Measure

[requirement]
====
[%metadata]
identifier:: /req/vector/units
part:: An Encoding SHALL support qualifying distance properties identified as "uom-qualified" with a unit of measure (pixel, millimeter, inch, percentage, meter, foot).
part:: A Renderer SHALL support applying the appropriate unit transformation when rendering elements specifying a uom-qualified distances.
====

[[req-vector-marker]]
===== Symbolizer `marker` property

[requirement]
====
[%metadata]
identifier:: /req/vector/marker
part:: An Encoding SHALL support defining a `marker` Symbolizer property as an array of graphical elements (Graphics).
part:: A Renderer SHALL support drawing the graphical elements of a marker at the points of vector geometry (for points and line strings) and at the centroid of polygons.
====

[[req-vector-graphics]]
===== Graphics

[requirement]
====
[%metadata]
identifier:: /req/vector/graphics
part:: An Encoding SHALL support defining graphical elements (graphics) specifying a uom-qualified 2D real position offsetting the graphic from its original position.
part:: A Renderer SHALL support drawing the Graphics at the specified uom-qualified 2D position offset relative to its original position.
====

[[req-vector-dot]]
===== Dot Graphics

[requirement]
====
[%metadata]
identifier:: /req/vector/dot
part:: An Encoding SHALL support defining a Dot Graphic inheriting from a base Shape class specifying a stroke, with a uom-qualified `size` property and a `color` property that are the same values as the `width` and the `color` of its stroke.
part:: A Renderer SHALL support setting the `width` and the `color` of the stroke of a Dot when its `size` and `color` are set, and the reverse, so that the value set last applies to both.
part:: A Renderer SHALL support drawing a Dot Graphic as a filled circle whose diameter is its `size` (the `width` of its stroke), in its `color` (the `color` of its stroke).
====

NOTE: A Dot is a stroke drawn on a single point, as if a pen were put down and lifted again. A Dot with an outline is drawn with two concentric Dots, the larger one first.

[[req-vector-image]]
===== Image Graphics

[requirement]
====
[%metadata]
identifier:: /req/vector/image
part:: An Encoding SHALL support defining an Image Graphic with an `image` property referencing an image resource, an optional uom-qualified `hotSpot` position within the image, optional `tint` and `blackTint` Colors, and an optional `alphaThreshold` real number between 0 and 1.
part:: A Renderer SHALL support drawing the referenced image so that its `hotSpot` (by default, its center, `{ 0.5, 0.5 }`) is located at the position of the Graphic.
part:: A Renderer SHALL support recoloring the image so that each red, green and blue component _v_ (between 0 and 1) of each pixel becomes `tint` × _v_ + `blackTint` × (1 − _v_), using the same component of `tint` and `blackTint`.
====

NOTE: With the default `tint` (white) and `blackTint` (black), the image is drawn unchanged. For a monochrome icon, `tint` sets the color of its white parts and `blackTint` the color of its black parts, so that one icon can be drawn in a different color per category.

NOTE: `alphaThreshold` is meant for picking: a pixel of the image whose alpha value is below `alphaThreshold` is not considered part of the Graphic when selecting features on an interactive map. An Encoding stores it, but no Renderer requirement applies to it.

[[per-vector-image-alpha-test]]
[permission]
====
[%metadata]
identifier:: /per/vector/image-alpha-test
part:: A Renderer MAY use `alphaThreshold` as the threshold of an alpha test, by not drawing the pixels of the image whose alpha value is below it.
====

[[req-vector-text]]
===== Text Graphics

[requirement]
====
[%metadata]
identifier:: /req/vector/text
part:: An Encoding SHALL support defining a Text Graphic with a `text` unicode string content, a `font`, and an `alignment` with a horizontal (`horzAlignment`: `left`, `right` or `center`) and vertical component (`vertAlignment`: `top`, `middle`, `bottom`).
part:: A Renderer SHALL support drawing the `text` of a Text Graphic using the `font` and the `alignment` specified.
====

[[req-vector-fonts]]
===== Fonts

[requirement]
====
[%metadata]
identifier:: /req/vector/fonts
part:: An Encoding SHALL support defining Fonts with a `face` property indicating the face name (also known as the font _family_), a `size` specified in _points_, a `bold` flag indicating to use a bold weight if true, and an `italic` flag indicating to use an italic style if true.
part:: A Renderer SHALL support drawing text using the fonts specified.
====

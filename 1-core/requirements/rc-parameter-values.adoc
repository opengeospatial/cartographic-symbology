===== Expressions as Parameter Values

[requirement]
====
[%metadata]
identifier:: /req/parameter-values/expressions
part:: An Encoding SHALL support defining the value of any Symbolizer property, including members of object properties, using any type of Expression, not only Literal Expressions.
part:: A Renderer SHALL support evaluating Expressions used as Parameter Values for each feature or coverage cell being portrayed, and resolving the result to the data type expected by the Symbolizer property.
====

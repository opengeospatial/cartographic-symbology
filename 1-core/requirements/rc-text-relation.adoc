[[req-text-relation-like]]
===== Text `like` operator

[requirement]
====
[%metadata]
identifier:: /req/text-relation/like
part:: An Encoding SHALL support defining a `like` operation expression taking a text operand and a text pattern operand, where `%` in the pattern matches any sequence of zero or more characters and `_` matches exactly one character.
part:: A Renderer SHALL support evaluating a `like` operation expression to true if and only if the first operand matches the pattern specified by the second operand.
====

[[req-text-relation-not-like]]
===== Text `notLike` operator

[requirement]
====
[%metadata]
identifier:: /req/text-relation/not-like
part:: An Encoding SHALL support defining a `notLike` operation expression taking a text operand and a text pattern operand, using the same pattern syntax as the `like` operator.
part:: A Renderer SHALL support evaluating a `notLike` operation expression to the logical negation of the equivalent `like` operation expression.
====

[[req-text-relation-contains]]
===== Text `contains` operator

[requirement]
====
[%metadata]
identifier:: /req/text-relation/contains
part:: An Encoding SHALL support defining a `contains` operation expression taking two text operands.
part:: A Renderer SHALL support evaluating a `contains` operation expression to true if and only if the second operand occurs as a substring of the first operand.
====

[[req-text-relation-like]]
===== Text `like` operator

[requirement]
====
[%metadata]
identifier:: /req/text-relation/like
part:: An Encoding SHALL support defining a `like` operation expression taking a text operand and a text pattern operand, where `%` in the pattern matches any sequence of zero or more characters and `_` matches exactly one character.
part:: A Renderer SHALL support evaluating a `like` operation expression to true if and only if the first operand matches the pattern specified by the second operand.
====

[[req-text-relation-not-like]]
===== Text `notLike` operator

[requirement]
====
[%metadata]
identifier:: /req/text-relation/not-like
part:: An Encoding SHALL support defining a `notLike` operation expression taking a text operand and a text pattern operand, using the same pattern syntax as the `like` operator.
part:: A Renderer SHALL support evaluating a `notLike` operation expression to the logical negation of the equivalent `like` operation expression.
====

[[req-text-relation-contains]]
===== Text `contains` function

[requirement]
====
[%metadata]
identifier:: /req/text-relation/contains
part:: An Encoding SHALL support defining a call to the `contains` function taking two text arguments.
part:: A Renderer SHALL support evaluating `contains(a, b)` to true if and only if `b` occurs as a substring of `a`.
====

[[req-text-relation-starts-with]]
===== Text `startsWith` function

[requirement]
====
[%metadata]
identifier:: /req/text-relation/starts-with
part:: An Encoding SHALL support defining a call to the `startsWith` function taking two text arguments.
part:: A Renderer SHALL support evaluating `startsWith(a, b)` to true if and only if `a` begins with `b`.
====

[[req-text-relation-ends-with]]
===== Text `endsWith` function

[requirement]
====
[%metadata]
identifier:: /req/text-relation/ends-with
part:: An Encoding SHALL support defining a call to the `endsWith` function taking two text arguments.
part:: A Renderer SHALL support evaluating `endsWith(a, b)` to true if and only if `a` ends with `b`.
====

NOTE: The negations of the `contains`, `startsWith` and `endsWith` functions are written using the `not` operator, e.g., `not contains(name, 'Oslo')`.

NOTE: In CartoSym-JSON, `notLike` is encoded as `not` applied to `like` (see <<req-json-expressions>>).

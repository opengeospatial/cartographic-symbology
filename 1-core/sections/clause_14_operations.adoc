[[rc-text-relation]]
=== Requirements Class "Text Relation Operators and Functions"
==== Overview

[#img-uml-class-text-relation]
.Text Relation Operators and Functions UML Diagram
[plantuml, target=diagram-classes, format=png]
....
@startuml
enum TextRelationOperator
TextRelationOperator --|> Operator
TextRelationOperator : like
TextRelationOperator : notLike
interface TextRelationFunctions
TextRelationFunctions --|> Function : standard functions
TextRelationFunctions : contains(a : string, b : string) boolean
TextRelationFunctions : startsWith(a : string, b : string) boolean
TextRelationFunctions : endsWith(a : string, b : string) boolean
@enduml
....

This requirements class adds more advanced support for evaluating the relation between text values, including the _like_ and _not like_ operators,
and the _contains_, _starts with_ and _ends with_ functions. Their negations are written using the _not_ operator.

.comparison
[width="90%",options="header"]
|===
| Name         | Definition          | Data type and value   | Multiplicity
| like         | Like                | Text                  | 1..1
| notLike      | Not Like            | Text                  | 1..1
| contains     | Contains            | Text                  | 1..1
| startsWith   | Starts With         | Text                  | 1..1
| endsWith     | Ends With           | Text                  | 1..1
|===
